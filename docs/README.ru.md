# ChatGPT CDP MCP

[English](../README.md) · [Быстрый старт](QUICKSTART.md) · [Драйвер](DRIVER.md) · [Инструменты](TOOLS.md)

![Одна вкладка чата, подключённая к MCP-инструментам](assets/hero.png)

> Превращает одну уже авторизованную страницу ChatGPT в ограниченный MCP-сервер — через ваш CDP-драйвер и с проверяемой арендой одной вкладки.

Это отдельный MCP-пакет, а не часть Agent Herder. Он даёт клиенту MCP типизированные инструменты для страницы браузера, которой вы владеете. Конкретный способ управления браузером вы выбираете сами: Chrome DevTools Protocol, Playwright, BrowserClaw или собственный адаптер.

- Семь операций: создать, найти, поискать, выгрузить, отправить, изменить и скачать.
- Одна owned-вкладка на процесс MCP; перед каждой операцией проверяется lease.
- Существующие чаты доступны для чтения, а экспорт и записи разрешены только для нового disposable fixture-чата.
- В ответах MCP нет нативных browser ID — только opaque refs.
- Mock-драйвер позволяет проверить интеграцию без браузера и без аккаунта.

## Установка

```bash
npm install --global git+https://github.com/megamen32/chatgpt-cdp-mcp.git
```

Нужны Node.js 20+ и локальный модуль драйвера. Пакет не содержит авторизацию, cookies, профиль браузера или облачный прокси.

## За минуту

Безопасная демо-проверка без ChatGPT:

```bash
git clone https://github.com/megamen32/chatgpt-cdp-mcp.git && cd chatgpt-cdp-mcp && npm ci && CDP_CHAT_DRIVER_MODULE=./examples/mock-driver.mjs npm start
```

Для реальной страницы укажите свой модуль через `CDP_CHAT_DRIVER_MODULE`; контракт — в [DRIVER.md](DRIVER.md).

Полный список методов, параметры и границы — в [TOOLS.md](TOOLS.md). Важно: используйте только аккаунт и браузер, которыми вы вправе управлять, и соблюдайте применимые правила сервиса.
