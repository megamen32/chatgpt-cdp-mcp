# ChatGPT CDP MCP

[English](../README.md) · [Быстрый старт](QUICKSTART.md) · [Драйвер](DRIVER.md) · [Инструменты](TOOLS.md)

![Одна вкладка чата, подключённая к MCP-инструментам](assets/hero.png)

> Превращает одну доступную авторизованную страницу ChatGPT в ограниченный MCP-сервер: переиспользует вкладку или создаёт ровно одну, если доступной нет.

Это отдельный MCP-пакет, а не часть Agent Herder. Он даёт клиенту MCP типизированные инструменты для страницы браузера, которой вы владеете. Конкретный способ управления браузером вы выбираете сами: Chrome DevTools Protocol, Playwright, BrowserClaw или собственный адаптер.

- Переносимый контракт на десять операций; встроенный BrowserClaw-адаптер
  честно публикует шесть: создать, отправить, скачать, исследовать, искать в
  вебе и рисовать.
- Одна owned-вкладка на процесс MCP; перед каждой операцией проверяется lease.
- Существующие чаты доступны для чтения, экспорта и подтверждённой отправки;
  редактирование, скачивание media и task-инструменты остаются в новом
  disposable fixture-чате.
- В ответах MCP нет нативных browser ID — только opaque refs.
- Mock-драйвер позволяет проверить интеграцию без браузера и без аккаунта.

## Установка

```bash
npm install --global git+https://github.com/megamen32/chatgpt-cdp-mcp.git
```

Нужны Node.js 20+ и локальный модуль драйвера. Пакет не содержит авторизацию, cookies, профиль браузера или облачный прокси.

## За минуту

Безопасная демо-проверка без ChatGPT:

```bash
git clone https://github.com/megamen32/chatgpt-cdp-mcp.git && cd chatgpt-cdp-mcp && npm ci && CDP_CHAT_DRIVER_MODULE=./examples/mock-driver.mjs npm start
```

Для реальной страницы BrowserClaw укажите `CDP_CHAT_DRIVER=browserclaw`.
Он использует единственную ChatGPT-вкладку, доступную его BrowserClaw
MCP-сессии. Если доступной вкладки нет (в том числе когда видимая вкладка
принадлежит другой сессии), создаёт одну `https://chatgpt.com/` и удерживает
её для процесса MCP. При нескольких доступных вкладках укажите
`CDP_CHAT_BROWSERCLAW_PAGE`. Конфигурация — в
[CONFIGURATION.md](CONFIGURATION.md), контракт другого адаптера — в
[DRIVER.md](DRIVER.md).

Полный список методов, параметры и границы — в [TOOLS.md](TOOLS.md). Важно: используйте только аккаунт и браузер, которыми вы вправе управлять, и соблюдайте применимые правила сервиса.

`research`, `search` и `draw` работают через page-native control ChatGPT.
BrowserClaw-адаптер выбирает доступный элемент интерфейса, ждёт завершения и
не создаёт новую вкладку для каждого вызова. Для `draw` скачиваемым media может
быть PNG-снимок итоговой страницы, а не исходный image asset. Если capability
в аккаунте недоступна, драйвер возвращает явную ошибку.
